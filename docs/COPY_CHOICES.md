# Copy choices

These are the moments that matter most. Each has five options and one recommendation, given in a sentence. The recommended option is what's live now. To choose a different option, change one line in `content/copy.ts`, or tell me the number.

Where you wrote the line yourself, yours is option 1. If I recommend something else, I say why.

## Landing hero

| # | Option |
| --- | --- |
| 1 | Find the problem *you can't ignore.* |
| 2 | Every company starts as someone's problem. *Find yours.* |
| 3 | Somewhere, someone has a problem *only you will fix.* |
| 4 | 3 weeks. 1 real problem. *Yours.* |
| 5 | Start with a problem *worth 3 weeks.* |

**Recommended: 1.** It is six words, and it names the one thing ForgeX asks of a founder. It also sounds like conviction rather than a slogan, which is the feeling we want them to arrive with.

## Profile heading

| 3 | Here's what we know. Change anything that's wrong. |

## The four team replies

The founder sees the reply's headline on their page and in the email, then the team's note.

### Go

| # | Option |
| --- | --- |
| 1 | Go. Start building. |
| 2 | Go. This one's yours. |
| 3 | Approved. Start building. |
| 4 | Go. We think you're the one for this. |
| 5 | Yes. Build it. |

**Recommended: 2.** It gives them ownership, which is the feeling that carries a founder through week 2.

### Go, with a tweak

| # | Option |
| --- | --- |
| 1 | Go, with one change. |
| 2 | Go, with a tweak. Read our note first. |
| 3 | Nearly there. One change, then go. |
| 4 | Go, once you've made this change. |
| 5 | Yes, with a tweak. |

**Recommended: 2.** It keeps the reply's name and points straight at the one thing to do next.

### Let's talk

| # | Option |
| --- | --- |
| 1 | Let's talk before you start. |
| 2 | Let's talk. We'll find 15 minutes this week. |
| 3 | We'd like 15 minutes with you first. |
| 4 | Let's talk this through. |
| 5 | Before you build, a quick chat. |

**Recommended: 2.** It's specific about the time and the week, and it makes clear the team will reach out while the booking link is on hold.

### Try another

| # | Option |
| --- | --- |
| 1 | Try another. Here's where to look. |
| 2 | Not this one. Try one of these. |
| 3 | Let's find you a better fit. |
| 4 | Try another. Your answers are saved. |
| 5 | This one isn't your fit. These might be. |

**Recommended: 3.** It is the kindest "no" of the five. It turns a rejection into a shared next step, and the suggestions sit right underneath.
